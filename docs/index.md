# DDL-v1 Documentation

The **Datacustodia Dataset License, Version 1 (DDL-v1)** is an open,
non-commercial license for curated datasets. It lets anyone use, share
and adapt a dataset for non-commercial purposes, as long as they give
attribution — commercial use requires separate written permission.

The authoritative license text lives in
[`licenses/License.txt`](https://github.com/datacustodia/ddl/blob/master/licenses/License.txt)
in the source repository. These pages are a plain-language companion;
if anything here disagrees with the license text, the license text wins.

## The five mandatory requirements

1. **Free, worldwide right of use** — royalty-free, non-exclusive,
   irrevocable (except on breach).
2. **Non-commercial reuse only** — copy, distribute, adapt and process
   solely for Non-Commercial Purposes.
3. **Mandatory attribution** — name the Licensor, the dataset title and
   the `DDL-v1` version label in any public use, and mark adaptations.
4. **No commercial use without permission** — obtain prior written
   permission from the copyright holder first.
5. **Verbatim reproduction** — when the license text travels with the
   dataset, it must be reproduced verbatim and unmodified.
