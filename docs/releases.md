## Source distribution

The canonical source for the official release is the
`licenses/License.txt` file at the root of the source
repository. Distributions (mirrors, package archives, dataset
releases) must reproduce this file verbatim.

## How to upgrade

When a new official release is published:

1. Replace your local copy of `licenses/License.txt` with the
   new file from the official source.
2. Update the `DDL-v1` version label in your attribution.
3. Distribute the new license file verbatim with your next
   public release.
