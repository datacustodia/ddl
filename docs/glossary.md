# Glossary

Plain-language definitions of key terms used in DDL-v1. The
authoritative definitions are in Section 1 of the License.

| Term | Meaning |
| --- | --- |
| **Adapted Material** | A new work derived from or incorporating the Licensed Material (translations, joins, aggregates, fine-tuned models, etc.). |
| **Attribution** | The credit line identifying the Licensor, the dataset title, the `DDL-v1` version label, and where practicable a source URI. |
| **Commercial Use** | Any use primarily intended for commercial advantage or monetary compensation (selling, hosting for fee, paid services, internal R&D for a product, etc.). |
| **Dataset** | The structured collection of data distributed under DDL-v1, plus its metadata, schema, README and config files. |
| **Licensed Material** | The Dataset and any Adapted Material the Licensor has placed under the License. |
| **Licensed Rights** | The rights granted to You under the License (copyright + Sui Generis Database Rights). |
| **Licensor** | The Datacustodia Dataset License organization. |
| **Non-Commercial Purpose** | Any use that is not Commercial Use (academic research, education, open-source, personal study, non-profit journalism, government use). |
| **Publicly Released Usage Scenario** | Any use communicated to a third party (paper, dataset, model card, app, blog, mirror, etc.). |
| **Sui Generis Database Rights** | Database-specific rights, separate from copyright (e.g. EU database right). |
| **You** | Any individual or entity exercising Licensed Rights under DDL-v1. |
| **Your** | Belongs to You. |

Only stable releases (no suffix) are considered **official
releases** for the purposes of Section 6(c). When in doubt, the
build is treated as unofficial.
