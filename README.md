# Datacustodia Dataset License Version 1 (DDL-v1)

This repository hosts the **Datacustodia Dataset License, Version 1
(DDL-v1)**, an open, non-commercial data license authored and
maintained by the Datacustodia Dataset License organization. It
governs the use, redistribution and modification of curated datasets
released under its terms.

The complete, authoritative license text lives in
[`licenses/License.txt`](licenses/License.txt). This README is a
plain-language companion; in case of any discrepancy, the text in
`licenses/License.txt` — reproduced verbatim — prevails.

## 1. The Five Mandatory Requirements

DDL-v1 is built upon five non-negotiable requirements. Every use of
the Licensed Material must comply with all five:

  1. **Free, non-exclusive, irrevocable right of use worldwide.**
     The Licensor grants the public a worldwide, royalty-free,
     non-exclusive and (subject to termination for breach)
     irrevocable right to use the dataset.

  2. **Non-commercial reuse only.** Users are entitled to copy,
     distribute, adapt and process the dataset solely for
     Non-Commercial Purposes. Permitted activities include
     academic research, education, open-source software
     development, personal study, non-profit advocacy,
     journalism in non-commercial outlets, and government or
     public-sector use (see Section 3 of the License for
     illustrative examples).

  3. **Mandatory attribution.** In any *Publicly Released Usage
     Scenario*, users must provide appropriate Attribution
     indicating the source of the dataset. Attribution must
     identify the Licensor, the title of the Licensed Material,
     the version label `DDL-v1`, and where practicable a URI
     pointing to the source. Adapted Material must be marked
     clearly as such (see Section 5 of the License).

  4. **Commercial use is not granted.** Commercial Use of the
     Licensed Material is not covered by this open grant. Any
     commercial activity shall obtain **prior written
     permission** from the copyright holder. Separate commercial
     license negotiations are conducted at the Licensor's sole
     discretion (see Section 4 of the License).

  5. **Verbatim reproduction.** When this License is excerpted,
     referenced or distributed alongside the Licensed Material,
     it shall be reproduced verbatim in its original form. No
     modification, addition, deletion, translation or
     reformatting of the substantive provisions is permitted
     (see Section 6 of the License).

## 2. Typical Use Scenarios

  - **Academic paper using a DDL-v1 dataset.** Cite the dataset
    title, `Datacustodia Dataset License Version 1 (DDL-v1)`,
    and a link to the source. Include an "Adapted from" notice
    if the dataset has been modified. Compliant.
  - **Open-source library that bundles a DDL-v1 dataset.**
    Distribute the dataset under DDL-v1 verbatim and ship a
    `NOTICE`/`LICENSE` file pointing to this repository.
    Compliant.
  - **For-profit company using a DDL-v1 dataset to train a
    commercial model.** Contact the Licensor for a separate
    commercial license **before** any Commercial Use occurs.
    Non-compliant without prior written permission.

## 3. Compliance Checklist

Before publicly releasing any work that incorporates DDL-v1
material, confirm the following:

  - [ ] Attribution identifies the Licensor, the dataset title
        and the `DDL-v1` version label.
  - [ ] A source URI is provided where reasonably practicable.
  - [ ] Any Adapted Material is clearly marked as modified.
  - [ ] The use case is Non-Commercial (or a separate commercial
        license is in place).
  - [ ] The verbatim text of `licenses/License.txt` is shipped
        with the redistribution.

## 4. Commercial Licensing

To request a commercial license, contact the Datacustodia Dataset
License organization and provide:

  1. A description of the intended Commercial Use, territory,
     expected volume, duration and form of the Licensed Material
     involved.
  2. A statement of willingness to negotiate in good faith the
     terms of a separate written commercial agreement.

No Commercial Use should occur before a written agreement is fully
executed and any agreed consideration is paid or secured.

## 6. Translations

Plain-language translations of the License text are provided for
convenience only. They are **informative**; in case of any
discrepancy, the original English text in
[`licenses/License.txt`](licenses/License.txt) prevails (see
Section 21(c) of the License).

### Contributing a translation

To add or improve a translation of DDL-v1:

  1. Create a new directory under `licenses/i18n/` using the
     appropriate BCP 47 / ISO 639-1 language tag (for example
     `de_DE` for German in Germany, `fr_FR` for French in France,
     `ja_JP` for Japanese in Japan).
  2. Place the translation as `License.v1.txt` inside that
     directory.
  3. The translation must:

       - be derived from the **latest official release** of
         `licenses/License.txt`, not from any sub-version (see
         Section 6(c) of `licenses/LastestLicense.txt`);

       - preserve the **structure** of the License (Preamble,
         Sections 1 through 21, Annexes A and B, closing banner);

       - leave capitalized defined terms such as `Licensor`,
         `Licensed Material`, `Licensed Rights`, `Adapted
         Material`, `Attribution`, `Commercial Use`,
         `Non-Commercial Purpose`, `Publicly Released Usage
         Scenario`, `Sui Generis Database Rights` and `You`
         untranslated, or transliterate them consistently; and

       - be clearly marked at the top of the file as a
         non-authoritative translation of DDL-v1, with a pointer
         to the authoritative English text.

  4. Add an entry to the table above and link to the new file.

### Translation scope

The translation should cover all of:

  - the Preamble;
  - Sections 1 through 21;
  - Annex A (Approved Attribution Formats);
  - Annex B (Compatibility Notes); and
  - the closing banner.

Plain-language pages under `docs/` may also be translated;
contributions are welcome via the normal change process.
